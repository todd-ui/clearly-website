## Add an event

**On iPhone:** on **Schedule**, tap `Add event`.

1. Enter the event name and an optional location.
2. Pick one or more dates.
3. Choose `All day`, or set start and end times.
4. Under `Repeat`, choose `Never`, `Daily`, `Weekly`, `Every 2 weeks` or `Monthly`, with an end date or none.
5. Choose which kids it's for, add notes if you like, and tap `Create event`.

**On the web:** on **Schedule**, click `Add event`. Fill in the event, date and time. To repeat it, choose `Daily`, `Weekly`, `Every 2 weeks` or `Monthly` under `Repeat`, and an `Until` date. Add the location, kids and notes if you like, and click `Add event`.

A repeating event with no end date is added for the next 6 months. Your co-parent is told once, about the whole series.

## Edit or delete

Only the parent who added an event can edit or delete it.

**On iPhone:** open the event, tap `Event options`, then `Edit event` or `Delete event`. **On the web:** open the day, then click `Edit` on the event.

For a repeating event, choose this event only or this one and the ones after it. A deleted event comes off both calendars.

## Ask about an event

Use `Ask about this` on an event to start a topic about it.
