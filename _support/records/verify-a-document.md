Every PDF Clearly makes has a document ID on every page. It looks like CLR-XXXX-XXXX-XXXX.

To check one:

1. Go to [getclearly.app/verify](https://getclearly.app/verify/).
2. Enter the document ID from the PDF.
3. Add the PDF when the page asks for it.

Clearly compares the file with the one it made. If even one character was changed, it won't match. Anyone can check, without an account: your co-parent, a lawyer, a mediator or a court.
