Court-ready co-parenting records.

Most families hope they never need the record. Clearly hopes so too, and makes sure it’s ready if you do.

Every message is kept exactly as written. Every page of an exported record carries a document ID, and anyone can check it’s genuine.

For the record, it’s court-ready. Just in case.

What’s in a Clearly record.

Every word, exactly as written. Messages in Clearly can’t be edited or deleted by anyone, Clearly included. The record has the parents’ own words, with no analysis, scores or conclusions.

Numbered, timed and read. Each entry is numbered, timed by Clearly’s server in the family’s time zone, and shows when the other parent first opened it.

An ID and a page number on every page. Each document gets its own ID, and every page is numbered from it (for example CLR-7KQ4-0003), so a page can be cited in a filing or at a hearing.

Parenting time and money, summed up. Overnights with each parent from the schedule and accepted changes, how each topic stands, and who owes whom.

It says exactly what it covers. The cover states the period, the time zone and what’s included, and an “About this record” page explains how it was made.

Ready for the court file. Children can appear as initials, and a parent can sign the included declaration if the court asks for one.

Anyone can check it.

A judge, a lawyer or the other parent can scan the code on the cover or go to getclearly.app/verify and enter the document ID. Drop in the PDF and Clearly confirms it produced that exact file and that nothing in it has changed since.

The file is checked in the browser and never uploaded. Checking is free, and needs no account.

Clearly for professionals

Questions about records.

Can Clearly records be used in court? Courts decide what evidence they accept, and that depends on the jurisdiction and the case. Clearly gives you a complete, time-stamped record kept exactly as written, with a document ID on every page that anyone can check.

How can a judge check a Clearly record is real? Scan the QR code on the cover, or go to getclearly.app/verify and enter the document ID or drop in the PDF. Clearly confirms it produced that exact file and that nothing in it has changed.

Can messages be edited or deleted? No. Once posted, topics and replies can’t be edited or deleted by anyone, Clearly included.

Does Clearly sign or notarize records? No. Each record explains how it was made on its “About this record” page, anyone can check it online, and it includes a declaration a parent can sign if their court asks for one.

Can I keep my children’s names out of it? Yes. Choose initials when you export, and the children appear as initials throughout.

What if my co-parent says I changed the PDF? Anyone can drop the file into getclearly.app/verify. If even one character changed, it won’t match the document Clearly produced.

What Clearly is.

Clearly is a co-parenting app for the schedule, the money and the conversations. When a conversation needs it, Clearly steps in like a mediator, with wording that moves it toward an answer. You choose what to send, and every post stays on the record as written. When you agree, Clearly writes up what you both agreed so you can each accept the same words.
